
# QuickNotes

QuickNotes is a simple note-taking web application that helps users capture and organize ideas. Users can create notes, categorize them as Personal, Work, or Study, search their notes, and delete notes they no longer need.

## Features

- Add notes with categories.
- Validate empty notes and notes longer than 200 characters.
- Delete individual notes.
- Search notes without case sensitivity.
- Display the number of saved notes.
- Save notes using localStorage.
- Responsive layout for smaller screens.

## How to Run Locally

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Alternatively, use the Live Server extension in VS Code.
